# Internship Practice Repository

Welcome to my daily internship practice log! This repository serves as a dedicated space to document my learning journey, technical growth, and the daily tasks I tackle during my internship.

## Purpose
The goal of this repo is to maintain a consistent coding streak and provide a searchable history of the concepts, bugs, and features I work on every day.

##  Folder Structure
Each folder follows a `DD_MM_YYYY_Day` naming convention to keep the logs chronological and easy to navigate.

**Example:**
- `13_02_2026_Friday/` - Contains work completed on Friday, Feb 13th, 2026.
- `12_02_2026_Thursday/` - Contains work completed on Thursday, Feb 12th, 2026.
